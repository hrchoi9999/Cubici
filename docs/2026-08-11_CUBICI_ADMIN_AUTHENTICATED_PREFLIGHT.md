# Cubici 관리자 인증 DB/API preflight

## 목적

- 인증정보 누락 상태에서 보호 API 전체를 호출해 반복적으로 `401`이 발생하는 문제를 제거한다.
- 관리자 로그인, Bearer Token, 실제 개발 DB 조회를 한 번의 제한된 preflight로 검증한다.
- 실제 관리자 자격정보와 개인정보를 파일·로그·Git에 기록하지 않는다.

## 구현

- 인증정보가 없으면 기본 36개 API 호출 전에 `PREFLIGHT_BLOCKED`로 즉시 종료한다.
- 운영 또는 별도 환경은 런타임 Bearer Token이나 런타임 관리자 로그인 정보만 허용한다.
- `--local-ephemeral-admin`은 loopback local DB에서만 허용한다.
- 로컬 모드는 무작위 합성 `ADMIN_USER`를 생성하고 실제 `/accounts/admin-login`을 호출한다.
- 로그인으로 발급된 Token을 모든 보호 API 호출에 적용한다.
- 검증 종료 시 합성 관리자 계정을 삭제하고 Token은 프로세스 종료와 함께 폐기한다.

## 검증 결과

| 항목 | 결과 |
|---|---|
| 인증 누락 fail-fast | 통과, 전체 API 호출 전 차단 |
| 실제 `/accounts/admin-login` | HTTP 200 |
| 인증 방식 | runtime login |
| 기본 API | 36건 실행 |
| 데이터 기반 상세 API | 8건 실행 |
| 전체 | 44건 |
| 실패 | 0건 |
| 검토 | 2건, 기존 원장 차이 `-3,616원` |
| deferred | 7건, 외부 실송금·금융상품 기준·RawData 정밀 산식 |
| 합성 관리자 잔여 | 0건 |

## 범위 분리

- 회원상세의 legacy 결제이력, 회원평가 저장, 증빙 다운로드는 유료화 계획 보류에 따라 추가개발로 이동한다.
- 해당 기능은 구현 완료로 처리하지 않으며 현재 관리자 내부 기능 구현률 83.5%도 변경하지 않는다.
- PCS/PMS, 정산·상환·집계 산식 검산과 RawData 정밀 산식은 기존 내부 검산 잔여로 유지한다.
