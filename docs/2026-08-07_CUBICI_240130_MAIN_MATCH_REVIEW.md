# 운영 메인 페이지 240130 일치 검토

## 결론

현재 `https://cubici.co.kr/` 메인은 240130 버전과 동일하지 않다. Hero 영역의 배경, 모니터 이미지, 주요 문구는 240130 원본을 사용하지만, 헤더와 Hero 하단 서비스 소개 영역은 React에서 별도 구조로 구현되어 있다.

## 확인 결과

- 운영 페이지 HTTP 200 및 최신 배포 번들 반영 확인.
- 현재 Header는 흰색 배경이다. 240130 렌더 기준 Header는 진한 남색 배경이다.
- 현재 Hero는 첫 번째 슬라이드만 표시한다. 240130 `index.html`은 `visual01`부터 `visual04`까지 4개 슬라이드와 PC 모니터 3개 화면을 포함한다.
- 현재 Hero 아래에는 탭 바와 `쇼핑몰 운영을 하나의 흐름으로 관리합니다.` 텍스트 카드가 표시된다.
- 240130 원본은 `큐빅아이 주요 서비스` 제목 아래 통합정보, 매출정보, 정산정보, 머니뱅크 4개 컬러 카드와 `side-icon-1~4.png` 아이콘을 표시한다.
- 현재 React 서비스 소개 영역에는 원본의 컬러 카드, 아이콘, 카드별 링크/버튼 구성이 없다.
- 현재 하단 쇼핑몰 채널 영역은 240130 메인 원본 캡처의 서비스 소개 카드 영역과 구성 및 위치가 다르다.
- Footer 정보/높이/삭제 항목은 사용자가 별도로 요청한 최신 수정사항이므로 240130 원본과 다른 것이 정상이다.

## 근거 파일

- 240130 원본: `240130_큐빅아이/index.html`, `240130_큐빅아이/header.html`, `240130_큐빅아이/static/css/style-main.css`
- 현재 React: `user-web/src/pages/HomePages.jsx`, `user-web/src/styles/final-ui-foundation.css`
- 비교 캡처: `docs/240130_render_check/pc_index.png`

## 후속 작업 판단

서비스 소개 영역을 240130과 같은 느낌으로 복원하려면 `HomePages.jsx`의 Hero 하단 `final-main-feature`를 원본 `side-menu/menu-list` 구조와 이미지 자산 기준으로 재구성해야 한다. 헤더 남색 배경과 4개 Hero 슬라이드도 함께 맞춰야 전체 메인 일치도가 올라간다.
