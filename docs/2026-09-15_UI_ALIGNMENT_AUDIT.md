- 대상: https://cubici.co.kr 사용자 및 관리자 운영 화면
- 로컬 기준 커밋: f0b092d3e7cc548158fa1f04320b73f1c7ac1e88
- 요청 범위: 디자인 변경 없이 겹침, 잘림, 정렬 및 반응형 배치 검토
- 방법: Chrome 실제 화면 스크린샷, 읽기 전용 DOM 치수 측정, 관련 소스 대조. 소스 검토 담당 결과를 Master가 화면 증거와 대조함.
- 결과: 배치 문제 2건 확인. 코드, 설정, 운영 데이터 변경 및 배포 없음.

## 확인된 문제

### 1. [P2] 로그인 상태의 모바일 메인에 비로그인 영역이 노출되고 잘림

- 경로: `/`, 로그인 상태로 점검하던 화면에서 확인.
- 실제 CSS 뷰포트 너비 390px 및 768px에서 재현됨.
- 상단 통합정보/매출정보/정산정보/머니뱅크 링크가 간격 없이 이어짐.
- 로그인/회원가입 영역의 내부 너비가 1120px로 유지되어 390px 화면에서는 버튼 문구가 화면 밖으로 밀리고, 아이디/비밀번호 찾기 링크도 오른쪽으로 잘림. 768px에서도 내부 영역이 화면 폭을 초과함.
- 비로그인 메인과 대조: 390px에서 로그인 영역 너비 약 336px, 버튼 약 284.5px로 표시되어 정상적으로 화면 안에 들어옴. 별도 `/login` 페이지도 폰트 로딩 완료 후 정상 표시됨.

원인 근거:

- `user-web/src/pages/HomePages.jsx:207`: 인증 여부에 따라 `auth-main` / `public-main` 레이아웃을 선택함.
- `user-web/src/pages/HomePages.jsx:359`: 모바일 비로그인 영역이 인증 여부와 무관하게 렌더링됨.
- `user-web/src/styles/final-ui-foundation.css:2278`: 인증 메인의 비로그인 영역을 숨기는 규칙이 있음.
- 같은 파일 `:5088`: 동일한 선택자 우선순위의 뒤쪽 규칙이 해당 영역을 다시 표시함.
- 같은 파일 `:5105`, `:5167`, `:5248`: 탭 배치, 내부 너비, 버튼 보정이 `public-main-shell`에만 적용됨.
- `src/main/webapp/resources/rudicks/css/common.css:32`: `.inner`의 기존 `min-width:1120px`가 노출된 인증 메인 영역에 남음.

후속 수정 방향: 인증 메인에서 비로그인 영역이 보이지 않도록 표시 조건 및 CSS 우선순위를 정리하고, 로그인/비로그인 각각 390px와 768px에서 확인. 두 가지 화면 증상은 같은 원인이므로 한 건으로 집계함. 이번 검토에서는 수정하지 않음.

### 2. [P3] 모바일 매출/정산 목록 도구 모음의 불필요한 세로 스크롤

- 경로: `/cubici/salesInfo/sales`, `/cubici/calculateInfo/details`
- 390px 화면에서 보기설정 문구가 두 줄로 표시되고, 선택옵션 오른쪽 도구 모음에 작은 세로 스크롤 화살표가 보임. 초기 355px 매출 화면에서도 관찰됨.
- `div.table-top.flex-end.u10-table-controls` 측정값: `clientHeight=40`, `scrollHeight=41`, 계산된 overflow는 auto.
- 페이지 전체 가로 넘침이나 표 본문의 의도된 가로 스크롤과는 별개임.

원인 근거:

- `user-web/src/pages/CommercePages.jsx:413`: 공통 목록 도구 모음.
- `user-web/src/styles/final-ui-foundation.css:6145`: 라벨 높이 40px와 테두리 설정.
- `user-web/src/styles/user-web.css:920`: 공통 select 높이 42px.
- `user-web/src/styles/final-ui-foundation.css:6158`: 내부 select 높이를 별도로 보정하지 않음.
- 같은 파일 `:6572`: overflow-x auto 설정과 내부 높이 초과가 결합하여 세로 스크롤도 발생함.

후속 수정 방향: 디자인을 유지하면서 라벨/선택 상자의 내부 높이를 맞추고 스크롤 정책을 검증. 이번 검토에서는 수정하지 않음.

## 제한 및 변경 내역

- 관리자 로그인은 사용자가 수행함. 이후 화면 조회와 메뉴 열기/닫기만 수행하고 신청, 승인, 저장, 다운로드 등 업무 실행은 하지 않음.
- 모든 화면, 모달, 긴 목록의 모든 행, 모든 해상도를 검사한 전체 E2E가 아님.
- 업무 계산, 데이터 최신성, API 정확성, 접근권한 전체를 검증한 결과가 아님.
- 과거 디자인 기준 이미지와 픽셀 단위 비교를 수행한 것은 아님.
- 스크린샷은 검토에만 사용하고 별도 파일로 저장하지 않음. 계정 식별값, 인증정보, 실제 금융 데이터 행은 문서에 기록하지 않음.
- 변경 파일은 이 문서 및 원 작업공간 `.docs`의 요약 기록뿐임. 기존 관리자 E2E 7개와 참조 PNG 2개의 수정 및 기존 미추적 파일은 그대로 보존함.
- 커밋, 푸시, 배포는 수행하지 않음. 후속 코딩 작업에서는 위 두 범위만 최소 수정하고 focused 반응형 검증을 수행하는 것이 적절함.

## 후속 수정 상태

검토 이후 사용자의 수정 승인에 따라 위 두 문제를 로컬 소스에서 수정함. 로그인 대시보드 모바일 표시 조건과 같은 목록의 1024px 최소 폭 충돌도 관련 범위에서 보완함. 빌드 및 9개 폭 x 5개 화면 상태의 focused UI 검증 45/45가 통과함. 상세 내역은 `docs/2026-09-15_UI_ALIGNMENT_FIX.md` 참조. 위의 미수정 서술은 최초 검토 시점 기록이며, 운영 배포는 여전히 수행하지 않았음.
