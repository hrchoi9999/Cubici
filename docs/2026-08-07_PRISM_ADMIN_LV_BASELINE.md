# Prism 관리자 LV 공통 기준선

## 적용 범위

- 머니뱅크 운영 > 프리즘 지표 관리
- 환경설정 > Prism System
- 관리자 공통 헤더, 좌측 메뉴, 서브 비주얼, 본문 2열 레이아웃

## 판단

- LV 자료에는 관리자 전용 원본 디자인이 없다.
- 현재 관리자 공통 UI는 사용자 LV의 색상, 타이포그래피, 간격 체계를 관리자 업무 화면에 맞게 확장한 기준선이다.
- 후속 LV 적용에서도 공통 틀은 유지하고 화면별 검색, 표, 입력, 상세 영역만 보정한다.

## 이번 보정

- 우측 인앱 브라우저 폭에서 좌측 메뉴와 본문이 같은 높이로 보이도록 반응형 2열 구조 적용
- 링크, 탭, 버튼의 브라우저 기본 스타일 제거
- 비활성 legacy 안내 레이어 기본 숨김
- 관리자 화면 전환 시 문서 상단 이동

## 검증

- Cloudflare 정적 번들 build 통과
- 정적 bundle smoke 통과
- Prism System 목록 API 조회 확인
- 프리즘 지표 관리 목록 API 조회 확인
- 약 780px 폭에서 좌측 메뉴/본문 정렬 확인

## 남은 사항

- 관리자 LV 원본이 없으므로 사용자 LV와의 시각 언어 일치 기준으로 추가 미세 조정 필요
- 운영 도메인 반영 여부와 전체 관리자 화면 회귀검증은 별도 배포 단계에서 수행
