# Cubici 관리자 환경설정 CRUD 실 DB 검증

## 범위

- 요금제 관리
- 연계코드 관리
- 협력사 관리
- 개발용 Docker PostgreSQL `cubici-postgres-dev`, host port `55432`

관리자 계정과 머니뱅크 상품은 기존 실 DB 검증 범위이므로 제외했다. RawData는 직전 Batch에서 별도로 완료했다.

## 삭제 정책

- 요금제: 연계코드 또는 결제이력에서 사용 중이면 삭제하지 않고 HTTP 409로 응답한다.
- 연계코드: 삭제 시 `promotion_charge` 연결 행은 DB `ON DELETE CASCADE`로 함께 삭제한다.
- 협력사: 회원 또는 연계코드에서 사용 중이면 삭제하지 않고 HTTP 409로 응답한다.
- 미사용 협력사 삭제 시 담당자 행을 먼저 삭제한 뒤 협력사를 삭제한다.

## 데이터 보호

- 기존 운영 이관 데이터는 수정하거나 삭제하지 않는다.
- UUID 기반 테스트 코드로 생성한 레코드만 생성·수정·삭제한다.
- 테스트 성공·실패와 무관하게 `finally` 정리 구문으로 테스트 행을 제거한다.
- 테스트 데이터에는 실제 계정·연락처·결제정보를 사용하지 않는다.
