# 사용자/관리자 반응형 적용 현황

## LV 원본

- `240130_큐빅아이/static/css`에는 1279px, 1023px, 767px 중심의 반응형 규칙이 있다.
- PC 헤더와 모바일 헤더/내비게이션을 분리한 구조다.
- `user-web/public/final-ui/static/css`의 주요 CSS 5개는 LV 원본과 SHA-256 기준 동일하다.

## 사용자 화면

- viewport meta 적용
- LV CSS 원본을 `final-ui-foundation.css`에서 직접 import
- React 공통 레이아웃에 PC/모바일 헤더와 모바일 하단 내비게이션 구현
- 대표 사용자 경로의 모바일 overflow focused E2E가 존재함
- 판단: 반응형 기반은 적용됐으나 모든 사용자 경로의 최신 운영 회귀검증은 남아 있음

## 관리자 화면

- viewport meta 적용
- 공통 관리자 레이아웃에 960px 2열 축소, 680px 단일열 전환 적용
- 넓은 업무용 표는 화면 축소 대신 가로 스크롤을 허용하는 방식 사용
- Prism System과 프리즘 지표 관리 화면은 약 780px 폭에서 확인함
- LV 원본에는 관리자 전용 UI가 없어 사용자 LV의 시각 언어를 확장 적용함
- 판단: 공통 반응형 틀과 Prism 2개 화면은 적용됐으나 전체 관리자 화면 최적화/검증은 미완료

## 결론

- 사용자와 관리자 모두 반응형 웹을 목표로 개발 중이다.
- 사용자 화면은 LV 반응형 소스를 직접 이식한 상태다.
- 관리자 화면은 별도 반응형 구현이며 아직 전체 화면 적용 완료로 볼 수 없다.

## 확정 개발 원칙

- 사용자 화면과 관리자 화면을 모두 반응형 웹으로 통일한다.
- 관리자 화면은 PC의 정보 밀도와 업무 효율을 기준으로 설계한다.
- 태블릿에서는 좌측 메뉴와 본문 2열을 유지하되 폭을 유동적으로 조정한다.
- 모바일에서는 메뉴와 본문을 단일열로 전환한다.
- 넓은 업무용 표는 열을 과도하게 축소하지 않고 가로 스크롤과 핵심 열 우선 표시를 사용한다.
- 화면별 반응형 적용 여부는 PC, 태블릿, 모바일 focused 검증으로 확인한다.
