# 사용자 화면 전체 회귀검증 및 외부 연동 분류

기준일: 2026-08-09

## 완료 기준

- 화면 복원율, 내부 기능 구현율, 외부 연동 추가개발을 분리한다.
- 외부 사업자 계약·인증키·운영망이 필요한 기능은 현재 회귀 실패로 계산하지 않는다.
- 로컬 DB/API에서 재현 가능한 결함은 Backend 보완 대상으로 처리한다.

## 회귀 결과

| 구분 | 결과 |
|---|---|
| 사용자 production build | 통과, Vite 2.10초 |
| PC/모바일 route smoke | 2/2 통과, PC 42 route 및 모바일 17 alias 포함 |
| 공통/edge focused smoke | 30/30 통과 |
| Backend 전체 pytest | 127/127 통과, DB E2E 6개 포함 |
| 사용자 DB 연동 Playwright | 10/10 통과 |

사용자 DB E2E는 회원가입, 회사정보 수정, 쇼핑몰 CRUD, 판매·반품·정산·캘린더,
머니뱅크 신청·문서 업로드·약관 동의·전자서명·해지, 공지·FAQ·요금 상세를 포함한다.

## Backend 보완

- `latest_fee_rate`가 `ADVANCE`와 `REPAYMENT` 요율 평균을 반환하던 문제를 수정했다.
- 사용자 화면의 이용 수수료율은 `ADVANCE` 요율을 우선하고, 해당 유형이 없을 때만 평균값을 사용한다.
- Backend focused DB E2E 및 전체 127개 테스트로 재검증했다.

## 외부 연동 추가개발

| ID | 기능 | 현재 분류 |
|---|---|---|
| ADD-EXT-01 | SMS/휴대전화 인증 발송·확인 | 인증 사업자 선정, 계약, 키 설정 후 개발 |
| ADD-EXT-02 | 이메일 인증 및 메일 발송 | 메일 사업자/도메인 정책 확정 후 개발 |
| ADD-EXT-03 | 우편번호·주소 검색 | 주소 API 사업자 선정 후 개발 |
| ADD-EXT-04 | 신분증·면허·공동인증서·계좌 본인확인 | 인증기관 연계와 보안 심사 후 개발 |
| ADD-EXT-05 | 쇼핑몰 실 API 인증·수집 | 쇼핑몰별 운영 키와 수집 어댑터 개발 |
| ADD-EXT-06 | PG 결제·취소·환불·영수증 | PG 계약과 결제정보 보호 설계 후 개발 |
| ADD-EXT-07 | 알림톡/SMS/이메일 운영 발송 | 발송 정책·템플릿·수신동의 확정 후 개발 |

## 내부 잔여 기능

- 사용자별 요금제·결제·서비스 이용이력 API
- 공지/Q&A 첨부파일, 사용자 수정·삭제, 관리자 답변 전체 흐름
- 판매·반품·정산의 legacy 미제공 열과 대용량 누적 집계
- 통합정보 차트의 운영 데이터 및 legacy 산식 대조
- 머니뱅크 지급·상환 산식의 legacy 원장 기준 최종 검산
