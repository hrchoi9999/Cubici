# 운영 진입 경로 및 사용자 세션 오류 보완

## 확인 결과

- 관리자 `/admin-spa`는 Cloudflare에서 관리자 번들을 제공했지만 React route alias가 없어 미구현 경로 화면으로 진입했다.
- 사용자 메인 요약 API는 만료된 토큰에 `401 token expired`를 반환했으나 화면이 빈 요약값을 0원으로 표시했다.
- 두 현상은 DB 데이터 소실이 아니라 프런트엔드 경로 및 만료 세션 처리 문제다.

## 수정 범위

- `/admin-spa`, `/admin-spa/`를 관리자 기본 진입 경로 `/admin`으로 정규화한다.
- 사용자 인증 API가 401을 반환하면 로컬 세션을 제거하고 현재 경로를 `returnUrl`로 보존해 로그인 화면으로 이동한다.

## 검증 기준

- `/admin-spa` 접근 시 큐빅아이 통합정보 화면으로 이동한다.
- 만료 사용자 토큰으로 메인 접근 시 0원 화면을 유지하지 않고 로그인 화면으로 이동한다.
- 사용자 및 관리자 production build와 변경 범위 focused E2E를 통과한다.
