# Cubici 머니뱅크 예외 흐름 DB E2E

## Batch 범위

- 대상: A07 신청 관리, A08 심사 승인
- 흐름: 서류 보완 요청/재제출, 신청 거절, 이용조건 거절
- 환경: `cubici-postgres-dev` (`127.0.0.1:55432`)
- 제외: 운영 DB 쓰기, 외부 연동, 운영 배포

## 변경 사항

- 현재 LV 사용자 화면의 제목과 접근성 식별자에 맞게 예외 흐름 E2E를 갱신했다.
- DB E2E runner가 한 개 이상의 focused spec을 받을 수 있게 확장했다.
- `TERMS_REFUSED`와 legacy 코드 `51`을 관리자 심사 조회 범위와 거부 집계에 포함했다.
- 관리자 심사 화면에서 이용조건 거절 건을 수수료 조정 건으로 오분류하지 않고 `거부`로 표시한다.
- 사용자 화면은 `동의거부`, API 상태는 `TERMS_REFUSED`, 관리자 판정은 `거부`로 각각 검증한다.

- 서류 보완 요청 -> 사용자 재업로드 -> `REQUEST`: 1 passed
- 신청 거절 -> 사용자 `거절` 표시: 통과
- 이용조건 거절 -> `TERMS_REFUSED` 저장: 통과
- 관리자 거부 범위 조회/거부 집계/화면 `거부` 표시: 1 passed
