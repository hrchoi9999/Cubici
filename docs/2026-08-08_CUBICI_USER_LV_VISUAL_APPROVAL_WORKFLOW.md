# 사용자 LV 화면 이미지 승인 방식

점검일: 2026-08-08

## 배경

- 기존 LV 운영 사이트는 현재 확인할 수 없다.
- LV 소스가 React에 포함됐는지만으로 화면 복원 완료를 판단할 수 없다.
- 실제 LV 화면 캡처와 현재 React 출력 사이에 차이가 확인됐다.
- 이후 사용자 화면 완료 기준은 코드 사용 여부가 아니라 승인된 출력 이미지로 한다.

## 기준 우선순위

1. 실제 LV 화면 캡처본
2. `240130_큐빅아이` HTML/CSS/이미지
3. 현재 React 구현

캡처본과 240130 소스 렌더가 다르면 캡처본을 시각 기준으로 우선하고, 기능과 반응형 동작은 240130 소스를 참고한다.

## 확인된 기준 캡처

- 경로: `D:\Cubici\큐빅아이 231130 JPG`
- PC: 13장, 기준 폭 1920px
- 모바일: 4장, 기준 폭 720px
- 합계: 17장
- 주요 범위: 로그인, 메인, 공통 서브, 매출/상품/판매/반품/정산, 공지/Q&A/FAQ, 가입정보, 머니뱅크 소개, 모바일 로그인 전/후, 전체 메뉴, 통합정보

## 화면별 산출물

각 화면마다 다음 이미지를 함께 관리한다.

1. `reference`: LV 캡처 원본
2. `current`: 동일 viewport와 로그인/데이터 상태의 현재 React 전체 화면
3. `compare`: reference/current 병렬 비교 이미지
4. `approved`: 의견 반영 후 승인된 React 최종 이미지

승인 전 화면은 LV 구현 완료로 계산하지 않는다.

## 비교 기준

- 공통 헤더와 메뉴
- 페이지 전체 폭과 콘텐츠 시작 위치
- 섹션 순서와 누락 여부
- 글꼴, 크기, 굵기, 색상
- 배경색, 이미지, 아이콘
- 카드, 표, 검색, 입력 영역 배치
- 세로 여백과 페이지 전체 높이
- 로그인 전/후 상태 차이
- PC/태블릿/모바일 반응형 전환

## 작업 순서

### Visual Batch V1

- PC 로그인 후 메인
- PC 로그인 전 메인
- 모바일 로그아웃 메인
- 모바일 로그인 메인
- 모바일 전체 메뉴

메인 화면군의 기준/현재/비교 이미지만 생성하고 코드 수정은 하지 않는다.

기본 용어에서 `메인화면`은 `pc_index_login.png` 기준 로그인 후 PC 메인을 의미한다. 로그인 전 화면은 반드시 `비로그인 메인`으로 표기한다.

### Visual Batch V2

- 공통 서브 레이아웃
- 통합정보
- 매출/상품/판매/반품/정산 화면군

### Visual Batch V3

- 공지/Q&A/FAQ
- 가입정보/마이페이지
- 머니뱅크 소개 및 파생 사용자 화면

## 승인 후 구현

- Visual Batch별 의견을 먼저 확정한다.
- 승인된 목표 화면을 기준으로 해당 사용자 UI Batch를 구현한다.
- 구현 후 같은 viewport와 상태로 다시 캡처해 `approved` 이미지를 만든다.
- 사용자 화면 전체 승인 전에는 관리자 LV 작업을 재개하지 않는다.

## 현재 판단

- 기존 사용자 Batch 1~9의 build/smoke 통과는 기능적 기준이다.
- 시각 승인 기준으로는 사용자 LV 복원이 완료되지 않았다.
- 다음 작업은 Visual Batch V1이며, 구현이 아니라 메인 화면군 비교 이미지 작성이다.
