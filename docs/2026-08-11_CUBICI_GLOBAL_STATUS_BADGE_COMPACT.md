# Cubici 전역 상태 배지 축소

## 범위

표의 `해지서비스`, `상태`처럼 데이터 상태를 표시하는 타원형 컬러 배지를 약 10% 축소했다. `보기`, `환급`, `검색`처럼 클릭 동작이 있는 버튼은 크기를 유지했다.

## 변경값

| 구분 | 이전 | 변경 |
|---|---:|---:|
| 관리자 상태 배지 높이 | 30px | 27px |
| 관리자 상태 배지 폰트 | 13px | 12px |
| 관리자 상태 배지 좌우 패딩 | 15px | 13px |
| 사용자 상태 배지 높이 | 30px | 27px |
| 사용자 상태 배지 폰트 | 13px 또는 12px | 12px 또는 11px |
| 사용자 상태 배지 좌우 패딩 | 12px | 11px |

## 적용 화면

- 관리자: Error Log, 고객문의, 펌뱅킹 전문, 이용상세, 회원정보, 휴면/해지, 서버관리의 상태 표시 11개 위치.
- 사용자: 판매현황, 반품/교환, 정산상세 상태 표시.
- 클릭 동작이 있는 `button.sBtn.rBtn`은 적용 대상에서 제외했다.

## 검증

| 항목 | 결과 |
|---|---|
| 관리자 production build | 통과, 75 modules |
| 관리자 D01·D02 focused E2E | 4/4 통과 |
| 사용자 production build | 통과, 42 modules |
| 사용자 판매·반품·정산 focused E2E | 6/6 통과 |
| 관리자 계산 스타일 | 높이 27px, 폰트 12px 확인 |

사용자 focused E2E 최초 실행은 테스트 고정 포트 4310과 preview 포트 4175 불일치로 실패했다. 동일 빌드를 4310에서 재실행해 6/6 통과했다.
