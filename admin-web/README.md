# Cubici Admin Web

React frontend for Cubici administrator screens.

## Scope

- Admin login
- Dashboard
- Merchant/user management
- Sales/returns/settlement management
- Advance payment application review
- Contract management
- Repayment/redemption operation
- Audit and operation history

## Migration Rule

Use existing admin JSP screens, CSS, images, fonts, table layout, search forms, and workflow as reference. Rebuild implementation as React components.
